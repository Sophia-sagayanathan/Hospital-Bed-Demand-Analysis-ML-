# 🏥 Hospital Bed Demand & Patient Risk Prediction using Machine Learning

## 📌 Project Overview
Hospitals often struggle with timely bed allocation due to sudden spikes in high-risk patients.  
This project uses **machine learning** to identify patients who are at **high risk of requiring hospital beds** based on clinical and diagnostic indicators.
The model helps support **hospital resource planning and early intervention decisions**.

## 🎯 Objective
- Predict whether a patient is **High Risk (1)** or **Low Risk (0)**
- Estimate potential **hospital bed demand**
- Support data-driven healthcare decision-making

## 📊 Dataset Description
The dataset contains anonymized patient health indicators including:
- Age  
- Gender  
- Heart Rate  
- Systolic & Diastolic Blood Pressure  
- Blood Sugar  
- CK-MB  
- Troponin  
- Diagnosis Result  

## 🛠️ Tools & Technologies
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- Google Colab  

## 🤖 Machine Learning Model
- Algorithm: **Random Forest Classifier**
- Train-Test Split: 80–20
- Model Evaluation Metrics:
  - Precision
  - Recall
  - F1-score
  - Confusion Matrix

### Model Performance
- Accuracy: **~89%**
- Balanced precision and recall for both classes


 
- Elevated Troponin levels
